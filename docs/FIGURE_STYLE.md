# Figure style guide

How every results figure in this repo is made. Reference implementation: `docs/results_v2/pgf/style.tex`
(colours, pgfplots styles, legend glyphs) and `docs/results_v2/make_pgf.py` (panel helpers, one `fig_*`
function per figure). Example of a figure that follows this guide: `fig_leaky_cond` -> `pgf/side/leaky_cond.tex`.

## Pipeline

- Figures are **pgfplots/TikZ**, never matplotlib images. Python reads the run outputs and writes a
  self-contained `tikzpicture` with the data inline (`write("side"|"fused", name, tex)`); the `.tex`
  report `\input`s it. Generated files start with `% generated by make_pgf.py -- do not edit`.
- Numbers shown on a figure (titles, annotations) come from a JSON or CSV written by an analysis
  script, never typed by hand.
- Add a new figure as a `fig_<name>(R)` function in `make_pgf.py` and register it in `main()`, so
  `build.sh` regenerates everything.
- Before calling a figure done, compile it and look at the rendered PDF: check for overlapping
  titles, hidden tick labels and clipped markers.

## Layouts

- **side**: Llama and Qwen in separate panels with the same axes. For a 2-column figure, Llama is
  left and Qwen right. For a 3+-column figure (one column per eval), use one row per model and a
  bold model name as the first column's `ylabel`.
- **fused**: both models in one axis. Llama uses the circle family and Qwen the triangle family. In
  dot plots, each row holds both models, offset ±0.2.
- Use `groupplot(...)`. When rows are shared, y tick labels appear only in the first column. Column
  titles go on the top row only. Put the x label once, on the bottom middle panel.
- Panel sizes: 2 columns at `W2 = 2.45in`, 3 columns at about 1.55–1.62in. Dot-plot height comes
  from `H_DOTS(n)`. Use `vsep` of at least 1.5cm when the lower row has a title.

## Encoding (identical in every model-level figure)

| Channel | Meaning | Values |
|---|---|---|
| colour | kind of extra data | grey `kNone` none, blue `kU` UltraChat, orange `kA` ambivalent, aqua `kC` contrarian, black `kNat` natural model / its directions |
| fill | how extra data was made | filled = self-distilled, hollow = off-policy |
| shape (side) | special cell | diamond = C-same, faded small = seed replicate, square = extra-data-only control or `nat_onpolicy`, x = orthogonal component `w` |
| shape (fused) | model | circle = Llama, triangle = Qwen |

- Always use `mstyle(name, ...)` / `series(...)` so a cell gets the same mark in every figure.
  Don't invent per-figure colours. Don't reuse kind colours for a different meaning.
- Line plots over eval domains (H1 only) use `dIn`/`dMed`/`dSyco`.

## Marks and references

- Dot plots are the default for "one number per cell or direction": the cell name sits on the y
  tick in `\ttfamily`, the value is on x, and the 95% CI is a thin horizontal bar in the mark's
  colour. Use `zebra` row bands, with `extra y ticks` at group boundaries.
- References go behind the data:
  - `band(...)` (light grey) = range over random directions, the null.
  - `vline(0)` (dashed) = no effect.
  - A thick translucent black bar = group mean, when the figure compares groups.
- Scatter plots are only for continuous x with many independent points. When x clusters into
  groups, use a dot plot grouped by cluster instead.
- Thin lines (0.4–0.6pt), with markers about 1.7–1.9pt. Grids `gridc`, axis lines `ink2`.
  Only left and bottom axes are drawn.

## Text

- Titles name the eval or quantity. The statistic for a panel goes on the title's second line in
  `\normalfont`, e.g. `$\Delta T=+0.16^{*}$ [+0.11, +0.20]`. `*` means Holm-corrected p < 0.05, and
  the caption defines it.
- Axis labels define the quantity in words the first time, e.g. "T = share of the natural model's
  sycophancy removed".
- When the grouping isn't otherwise visible, put it in the row label, e.g. `C-self (0.57)` =
  conditionality.
- The legend goes below the figure and is built from the `\lg*` glyph macros in `style.tex`. Use
  `\legendside`/`\legendfused` for model-level figures, or a figure-specific legend that reuses the
  same glyphs.
- No em dashes. The caption says what the figure shows and states the result, including when it
  contradicts the prediction. Leave "how to read this" boxes out of slides.

## Statistics shown on figures

- Use only one point per independent unit. Average seed replicates into their cell (or show them
  faded) and never count them as extra n in a correlation.
- Don't report a correlation across two clusters as a trend. If x splits into clusters, compare
  the groups and report the within-cluster ρ as well.
- Say which kind of uncertainty a figure shows:
  - **item bootstrap**: resample eval items, models fixed. This covers "these specific
    MOs/directions".
  - **cell-level permutation**: covers "MOs built this way". With 3 vs 3 cells the minimum
    two-sided p is 0.10.
- Report raw p and Holm-corrected p over the family of panels. The 95% CI comes from a paired
  bootstrap, with B ≥ 10,000 for figure-level contrasts.
- Show the random-direction null whenever a transfer value T is plotted.

## Checklist

1. Data comes from a script; the figure is a `fig_*` in `make_pgf.py`.
2. Encoding comes from `mstyle`, and the legend uses the shared glyphs.
3. Null band and zero line are drawn; group means are shown if groups are compared.
4. Statistic in the title or caption, with its unit of resampling and multiple-comparison correction.
5. Rendered and inspected: no overlapping text, no hidden tick labels, x ranges set per model when
   scales differ.
